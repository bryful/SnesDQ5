# SnesDQ5

SNES版ドラゴンクエスト5用プレイヤー。Androidを主対象、Windowsを動作確認用とします。開発中です。
ROMは付属しません。手元のROMを選択してください。

## 現在使える機能

- Snes9xによるゲーム実行・映像・音声
- ROM変更と前回ROMの再読込
- SRAMの定期保存（10秒間隔、バックグラウンド移行時、正常終了時）
- ステート保存・復元：5スロット
- キーボード、SDL2のゲームコントローラー入力、タッチボタン
- A/B、X/Yの入替
- 1/2/3/4/8倍速。SPCを等速にする制御は実験段階です。
- 戦闘報酬の経験値・ゴールド倍率：1（無効）/4/8/16/32/64/128倍。日本語v1.0 ROM専用。

仲間加入率・ドロップ率・装備制限解除に対応しました。加入・ドロップは下記の適用条件があります。モンスターのレベル上限99と、通常使用時のアイテム非消費にも対応しました。
確認済み範囲は [検証記録](docs/VERIFICATION.md)、採用理由・条件は [依存関係](docs/DEPENDENCIES.md) を参照してください。

## ビルド

まず `pwsh -File scripts/setup.ps1` で固定バージョンの依存ソースを取得します。

Windows：Visual Studio 2026のC++デスクトップ開発とCMakeを用意し、`pwsh -File scripts/build-windows.ps1`。
実行ファイルは `build/windows/Release/SnesDQ5.exe`。

Android：JDK21、Android SDK35、NDK30.0.16248370、CMake3.22.1を用意し、`pwsh -File scripts/build-android.ps1`。
必要なら `-SdkPath` と `-JavaHome` を指定します。APKは `android/app/build/outputs/apk/debug/app-debug.apk`。
APK内の全共有ライブラリについて16KBアライメントを自動検査します（Python3が必要）。
このAPKは開発用署名です。リリース署名・配布物の作成は別工程です。
署名付き配布版は `scripts/build-android.ps1 -Configuration Release`。署名設定と配布手順は [docs/RELEASE.md](docs/RELEASE.md) を参照してください。

## 操作

`Open ROM` で選択。WindowsではROMのドラッグ＆ドロップとコマンドライン引数にも対応します。
`Menu` またはEscで設定・ステート保存画面を開きます。メニュー表示中はゲームを停止します。

| SNES | キーボード |
| --- | --- |
| 十字キー | 矢印 |
| B / A / Y / X | Z / X / A / S |
| L / R | Q / W |
| Start / Select | Enter / 右Shift |

Xbox／ProコントローラーはSDL2の既存マッピングとホットプラグ機能を使用します。
Androidはコントローラーでの利用を基本とし、未接続・切断時にはタッチパッドを自動表示します。接続時は自動で隠します。設定の `Show touch with pad` で常時表示にもできます。
WiizVを参考に、縦持ちは映像の下、横持ちは映像の左右へ操作ボタンを配置します。十字キー・ABXY・L/R・SELECT/START、複数指の同時押し、押下表示、A/B・X/Y切替に対応します。上部の `Menu` からタッチで設定を開けます。

| メニュー操作 | コントローラー |
| --- | --- |
| 項目移動・スクロール | 十字キー／左スティック |
| 決定 | 下側のフェイスボタン（Xbox A／Proコントローラー B） |
| 戻る・ゲーム再開 | 右側のフェイスボタン（Xbox B／Proコントローラー A） |
| ゲーム中のメニュー開閉 | 左スティック押し込み（L3） |

メニューの決定・戻るは物理位置で統一し、ゲーム内のA/B・X/Y切替とは独立しています。
設定はPlay／Saves／Options／Filesに分かれ、L／Rでページを切り替えられます。十字キーで各設定へ直接移動でき、画面外の選択項目には自動スクロールします。
タッチでは内容を上下にスワイプしてスクロールできます。ゲーム復帰は常時表示のBack to game、右上の×、Androidの戻る、パッドの右側ボタンに対応します。メニュー外にゲーム画面が見えている場合は、その部分のタップでも復帰します。
現在の選択項目を枠で表示し、メニューを閉じた時の決定・戻る入力はボタンを離すまでゲームへ渡しません。
Android標準のROM・保存先選択画面はOS側の操作になります。Android実機のXbox／Proコントローラー操作は未確認です。

## 保存先

WindowsはSDL2のユーザー設定ディレクトリ（通常 `%APPDATA%/SnesDQ5/SnesDQ5`）。
Androidは初回に `Documents / SnesDQ5` からDocumentsを選択すると `SnesDQ5/rom` を作成します。
以降の設定・SRAM・ステートは選択した `SnesDQ5` に保存します。Androidのフォルダ権限はOSの選択画面で取得します。
選択前はアプリ内部領域へ保存し、保存先選択時に既存の同名ファイルを上書きせず移行します。
ROM選択は `rom` を初期位置とするOSのファイル選択画面を使用し、別フォルダにも変更できます。
元ROMをアプリ内部へROM名でコピーし、起動時は保存したURIから再取得します。

保存名は `ROM名.srm`、`ROM名.slot1.state` ～ `ROM名.slot5.state`。
ステート内のCRCとSRAMの `.meta` はROM取り違え防止用です。ファイル名にはハッシュを使いません。
同名ROMで保存先を共有するため、内容の異なるROMには別名を付けてください。
ステートは本アプリ専用形式です。コア更新時の互換性は未保証です。

## 公開・配布

ROM、セーブ、端末固有設定、Android署名鍵、ビルド生成物はGit対象外です。
独自コードのライセンスは [LICENSE](LICENSE)。組み込むSnes9xには非商用条件があり、アプリ全体を商用利用できるという意味ではありません。
配布時は `licenses/` と依存ソース取得手順を同梱します。`_dl`へのリリース作成は「リリースしてください」の指示後に行います。

Androidの画面方向は端末センサーで自動切替します。Rotateボタンや縦横固定設定はありません。
別の画面回転制御アプリで縦向きが強制されている場合は、そちらでSnesDQ5の固定を解除してください。実際の画面サイズで描画し、向きの変更待ちによる黒画面を回避します。

Androidの画面は端末の向きに合わせて自動回転します。別の回転制御アプリで縦固定にしている場合は、固定を解除するかSnesDQ5を制御対象から除外してください。

タッチパッド・映像・MenuはAndroidのステータスバー／ナビゲーションバー／切欠きを除いた領域に配置します。横画面でもMenuとLを分離し、右端の操作ボタンがシステムバーに隠れないようにしています。

ゲーム画面上部の `Save1` / `Load1` でスロット1へ保存・読込できます。
メニュー内の全5スロットのSave/Loadも、成功後は自動でメニューを閉じてゲームを再開します。失敗時はメニューを開いたままエラーを表示します。

横画面ではMenu/Save1/Load1を小さく表示し、上部・左右の操作領域を抑えてゲーム映像を拡大します。縦画面のボタンサイズは維持します。

経験値・ゴールド倍率はメニューの `DQ5 options` にあります。ROM識別・命令列・パッチ領域が一致する日本語v1.0だけ有効化します。元ROMファイルは変更しません。各敵の報酬を24ビットで加算し、上限は原処理と同じ0xFFFFFFです。通常の所持金・キャラクター経験値の上限は別のゲーム側仕様です。

ステート保存には適用中の倍率も含め、読込時に復元します。旧形式のステートも読み込めますが、旧形式には倍率情報がないため経験値・ゴールドは1倍で復帰します。
全倍率の加算処理を対象ROMとSnes9xのCPU実装で検証済みです。実際の戦闘終了画面・全仲間への経験値分配を通した確認は未確認です。

倍率の開発検証はCMakeの `SNESDQ5_BUILD_REWARD_CHECKS=ON` で `reward-check` をビルドし、手元のROMパスを引数に実行できます。検証データは `build/reward-verification` に分離し、ROMはリポジトリに含めません。

`DQ5 options` の追加項目（日本語v1.0専用）：

- `Recruit eligible monsters`：加入判定へ進んだモンスターの確率判定を通します。物語進行、主人公レベル、対象種族、加入数等の加入条件はゲーム側に残ります。会心固定の副作用がある「ひとしこのみ」は使用しません。
- `Guaranteed eligible drops`：ドロップ対象の戦闘で確率判定を通します。複数種類の敵を倒した場合など、ゲーム側がドロップ判定自体を行わない戦闘は対象外です。
- `Remove equipment restrictions`：装備可否の判定を解除します。空の持ち物枠は対象外です。

これらもステートへ保存し、読込時に復元します。旧形式ステートは新オプションを無効にして復帰します。対象ROM内の分岐・装備判定の実行は検証済みですが、実際の戦闘終了から加入・アイテム受取までの一連の確認は未確認です。

## 0.1.14：アイテム非消費・モンスターレベル上限99

DQ5 options の `Keep consumable items on use` は、通常のフィールド／戦闘での使用時に消費処理を省略します。売却・受け渡し・捨てる操作は対象外。道具の破損、自動発動、イベントによる消失は対象外です。
`Monster level cap: 99` は加入済みの仲間にも適用し、ゲーム本来の経験値・成長計算を使います。OFFにすると通常の上限へ戻り、獲得済みのレベル・能力値は維持します。人間・NPCの上限は変更しません。
両設定は設定ファイルとステートへ保存します。旧形式ステートではOFFへ戻します。対象ROMの処理をSnes9x CPUで実行して検証済みですが、実プレイでのアイテム使用・上限突破後の戦闘結果表示は未確認です。

## アプリアイコン

NesDQの参考画像に合わせた、グレーのSNESカセットと金色Vの生成アイコンを使用しています。元PNGとWindows用ICOはassets/iconに保存。Android用の各密度・アダプティブ画像はscripts/generate-icons.ps1で再生成できます。
